Electrical Power Calculator 
About:
This is my first Python project. It calculates electrical power using voltage and current.

Formula:
The program uses the electrical power formula,
P = V × I

Where:
P = Electrical power in watts (W)
V = Voltage in volts (V)
I = Current in amperes (A)

How It Works:
The program asks the user to enter the voltage.
It asks the user to enter the current.
It multiplies voltage by current.
It displays the calculated electrical power in watts.

Example:
If the voltage is 10 V and the current is 2 A:
P = 1o × 2 = 20 W
Output: Electrical power- 2o.0 watts

Python
